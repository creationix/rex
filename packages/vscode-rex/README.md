# vscode-rex (legacy)

> **This extension uses the legacy TypeScript parser.** It may not support all current language features. A Rust-based LSP is planned that will provide accurate diagnostics, completions, and type checking powered by `rex-core`.

VS Code extension for Rex, providing syntax highlighting for `.rex` and `.rexc` files, parser-backed diagnostics, outline view, and basic go-to-definition.
